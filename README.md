# 选题 skill（xuanti）

一个给 **AI 自媒体博主**找选题的 Claude Code 技能。

不用再刷一整天 X 还不知道拍什么。它每天替你做一件事：从 B站、YouTube、X、GitHub、Reddit、小红书挑出**别人做得最好的作品**，看清“他做了什么、为什么火”，整理进你的 Obsidian，再给你出几个今天能拍的干货选题。

## 它会做什么

- **开工前检查网站登录**：X、小红书、Reddit、B站、YouTube、GitHub 逐个检查，哪个没登录先告诉你，登好再开工，不会悄悄漏掉一个平台
- **4 个方向并行**：
  - **AI视频**：生视频（即梦、可灵、Seedance、写代码做动画、复刻爆款）+ 剪辑（剪口播、批量剪、动效包装）
  - **AI设计**：出图提示词、海报、封面、PPT、电商图
  - **AI内容**：用好各家大模型、提示词、AI 写作、AI 办公、智能体
  - **自动化**：AI 员工、工作流、自媒体流水线、开源工具
- **只收好东西**：两星以上才放；优先自己动手做东西、公开方法的 builder，少收搬新闻、卖课的；标出 🔥 低粉爆款（播放 ÷ 粉丝 ≥ 50 倍）、💰 广告、⚠️ 疑似搬运
- **先看你关注的博主**：好博主名单里的人有新东西优先收，再全网搜
- **每天只放新的**：已经收过的链接自动跳过；没有新的就写“没有”，不凑数
- **选题以干货为主**：优先“批量、能照着做、解决人人都有的痛点”的方法，比如怎么用 AI 批量做短视频、批量出图

## Obsidian 里的样子

```
AI/
├── 好博主名单                 ← 唯一一直累积的文件，顶部有“随手贴”
├── 2026-10-08 选题研究         ← 每天一个文件夹
│   ├── 📌 今日看板            ← 每天只看这一页：今天的内容 + 最推荐拍的 3 个 + 全部选题
│   ├── AI视频（生视频）
│   ├── AI视频（剪辑）
│   ├── AI设计
│   ├── AI内容
│   └── 自动化
└── 2026-10-07 选题研究
```

每个方向页面：顶部一张作品总表（点标题直接打开原视频，点 👇 跳到详细介绍），下面是每个作品“他做了什么、能借鉴什么”，最后是今天能拍的选题。

## 安装

```bash
git clone https://github.com/korazyy/xuanti-skill.git ~/.claude/skills/xuanti
```

然后打开 `SKILL.md`，改一下开头的「你的设定」：你的 Obsidian 文件夹、好博主名单。

需要：Claude Code、Python 3、`yt-dlp`、`gh`（GitHub 命令行）、OpenCLI（借你 Chrome 的登录状态读 Reddit、小红书）。

## 怎么用

在 Claude Code 里说：

> 今天的选题

也可以说“跑一下选题”“今天拍什么”。第一次想建一个方向的“底子”（一次挑 30 个），就说“重新做 AI设计 的底子”。

## 说明

- 只读公开内容；抓取慢速少量，被网站拦了就停，**不做任何绕过反爬的事**
- 小红书、Reddit 借用你自己浏览器的登录状态，不会碰你的密码
- 抓到的作品版权归原作者，页面里只写摘要和原链接
